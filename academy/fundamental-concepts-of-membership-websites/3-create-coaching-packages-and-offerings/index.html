Academy / Building Membership Websites with WordPress

Expanding Your Coaching Business with CoachKit by MemberPress

Create Coaching Packages and Offerings

{% raw %}

CoachKit allows you to easily create customizable coaching packages tailored to your clients’ needs.

3.1 Create Coaching Memberships

Offer memberships for different coaching levels (e.g., Basic Coaching, Premium, VIP).

  1. Go to MemberPress → Memberships → Add New.
  2. Create a new membership level that reflects your coaching package (e.g., “1-on-1 Coaching” or “Group Coaching”).
  3. Set the pricing for each membership (monthly, yearly, or one-time).
  4. Describe the benefits of the coaching package (e.g., weekly calls, progress tracking, access to exclusive materials).
  5. Drip content if needed—this is useful for releasing training modules or resources over time.

3.2 Sell Coaching Sessions or Packages

Offer single coaching sessions, or bundled packages like 5 or 10 coaching sessions, directly from your website.

  1. Go to MemberPress → Memberships → Add New.
  2. Create a specific membership for a coaching package (e.g., “5-Session Coaching Package”).
  3. Set pricing for the package, and configure billing frequency as one-time payment.
  4. Use the Rules feature to protect access to materials, exclusive coaching resources, or booking tools for clients who purchase these packages.

Pro Tip: Use upselling techniques by offering discounts on multi-session packages to encourage clients to purchase more upfront.
