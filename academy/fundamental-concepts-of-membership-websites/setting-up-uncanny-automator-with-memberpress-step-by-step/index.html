Uncanny Automator with MemberPress

Setting Up Uncanny Automator with MemberPress (Step-by-Step)

{% raw %}

Install & Activate both Uncanny Automator and MemberPress in WordPress.

  • You can find both plugins in the WordPress Plugin Repository.

Create a New Automation in Uncanny Automator:

  • Go to the Uncanny Automator plugin in WordPress.
  • Select Add New Recipe.

Choose Your Trigger (MemberPress Event):

  • In the "Trigger" section, choose MemberPress from the dropdown list.
  • Select an event like "User purchases a membership" or "User cancels a membership".

Define the Action:

  • After choosing your trigger, define what action you want to take when the event occurs.
  • Example actions might include:
    • Sending a welcome email via Mailchimp.
    • Adding the user to a course in a Learning Management System (like LearnDash).
    • Sending a notification to the admin or updating a Google Sheet.

Test & Activate the Recipe:

  • Once you’ve set up the trigger and action, test the automation to ensure it works as expected.
  • Activate the automation recipe once you’re satisfied.
