8. Responsive Design Patterns

{% raw %}

Several responsive design patterns can be used to build layouts that adapt to different devices. Here are some common ones:

a) Off-Canvas Navigation

This design pattern is useful for mobile navigation, where the menu is hidden off-screen and slides in when triggered.

.nav-menu {
  transform: translateX(-100%);
  transition: transform 0.3s ease-in-out;
}

.nav-menu.open {
  transform: translateX(0);
}

On smaller screens, the menu is hidden off-canvas, and the open class brings it into view.

b) Card Layouts

Card layouts are commonly used for showcasing content like products or blog posts. You can use Flexbox or Grid to create a card layout that stacks on smaller screens.

.cards {
  display: grid;
  grid-template-columns: repeat(auto-fit, minmax(250px, 1fr));
  gap: 20px;
}

This layout automatically adjusts the number of cards based on the screen size, with a minimum card width of 250px.

c) The Fluid Grid

The fluid grid pattern uses CSS Grid or Flexbox to create layouts that automatically adjust to the available space.

.grid-container {
  display: grid;
  grid-template-columns: repeat(auto-fill, minmax(200px, 1fr));
  gap: 10px;
}

This ensures that the layout adjusts as screen sizes change, creating a responsive and flexible grid structure.
