2. The calc() Function for Dynamic Layouts

{% raw %}

The calc() function allows you to perform mathematical operations directly in CSS, which can be useful for creating fluid layouts that combine fixed and flexible values. This function is especially helpful when you want to create responsive designs with mixed units (e.g., combining px, %, and vw).

Example: Using calc() to Combine Fixed and Flexible Sizes

.container {
  width: calc(100% - 40px); /* 100% of the viewport minus 40px for padding */
  padding: 20px;
}

In this example, the container will be responsive, taking up the entire viewport width minus 40px, ensuring consistent spacing.

Example: Dynamic Padding with calc()

.element {
  padding: calc(10px + 2vw); /* Combines a fixed value (10px) with a responsive value (2vw) */
}

This combines both fixed and viewport-based values for responsive padding.
