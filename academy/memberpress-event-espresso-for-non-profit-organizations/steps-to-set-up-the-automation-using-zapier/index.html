Academy / MemberPress & Event Espresso for Non-profit Organizations

Advanced Automation: Automatically Creating Personalized Discounts for Members in Event Espresso via Zapier

Steps to Set Up the Automation Using Zapier

{% raw %}

1. Set Up MemberPress as the Trigger

Trigger: A new membership purchase or renewal in MemberPress.

  1. Log into Zapier and create a new Zap.
  2. Set MemberPress as the Trigger App.
  3. Select the Trigger Event: “New Membership” or “Membership Renewed.”
  4. Connect your MemberPress account to Zapier by entering the necessary credentials.
  5. Choose the membership level(s) that will trigger the automation. For example, you might want to apply this only to members who join the “Wolf Protector” or “Bear Guardian” tiers.

2. Create Discount in Event Espresso

Action: Automatically create a personalized discount code in Event Espresso.

  1. After selecting MemberPress as the trigger, set Event Espresso as the Action App.
  2. Choose the Action Event: "Create Discount Code" (or similar, depending on the available actions in your integration).
  3. In the Create Discount Code step, configure the following:
    • Discount Code Name: Use a combination of the member’s name and the event name for a personalized feel (e.g., “JOHNDOE10”).
    • Discount Amount: Set the discount based on the membership level:
      • Wolf Protectors: 10% off
      • Bear Guardians: Free tickets
    • Validity Period: Define how long the discount code will be valid. You might limit it to a specific event date (e.g., valid for the upcoming “Wildlife Conservation Gala”).
    • Ticket Type: Specify which tickets the discount applies to (e.g., General Admission or VIP).

3. Send Discount Code to the New Member via Email

Action: Notify the new member with their personalized discount code.

  1. Set Gmail, Outlook, or any other email service as the next Action App (or use Zapier's built-in Email app).
  2. Create an email template that includes:
    • A personalized greeting with the member’s name.
    • A thank-you message for joining and supporting your non-profit.
    • The discount code generated in the previous step.
    • A call-to-action, encouraging them to register for the upcoming event using their discount.

Example Email Template:

Hi {{Member First Name}},

Thank you for joining our **Wolf Protector** membership! As a token of our appreciation, we’re excited to offer you a **10% discount** to attend our upcoming **Wildlife Conservation Gala**.

Here’s your personalized discount code: **{{Discount Code}}**

Use this code when you register at [Event Registration Link] to save on your ticket.

We look forward to seeing you there and continuing to work together to protect wildlife!

Best regards,
[Your Non-Profit Name]
  1. Configure Zapier to insert the discount code from the previous step into the email template automatically.

4. Test the Automation

Before going live, it’s essential to test the entire process:

  1. Run a test through Zapier:
    • Sign up for a new membership in MemberPress.
    • Verify that a new discount code is automatically generated in Event Espresso.
    • Ensure the discount code is sent via email to the new member.
  2. If the test is successful, the automation is working correctly. If something doesn’t work, check each step for errors or missing details.
