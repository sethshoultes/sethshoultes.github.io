Academy / MemberPress & Event Espresso for Non-profit Organizations

Advanced Automation: Automatically Creating Personalized Discounts for Members in Event Espresso via Zapier

Optional: Advanced Customization

{% raw %}

Member Tier-Specific Rules: You can use Zapier’s Filters to customize the automation further. For instance, set different rules for Wolf Protectors and Bear Guardians:

  • Wolf Protectors: 10% discount applied.
  • Bear Guardians: Free event tickets generated automatically (instead of a percentage discount).

Personalized Expiration Dates: You can dynamically set the discount code’s expiration based on the member’s join date or the event’s date.
