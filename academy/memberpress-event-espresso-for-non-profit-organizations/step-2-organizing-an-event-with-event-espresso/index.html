Academy / MemberPress & Event Espresso for Non-profit Organizations

Real-World Simulation: Managing Memberships and Events for a Non-Profit

Step 2: Organizing an Event with Event Espresso

{% raw %}

Scenario: You’re hosting your annual “Wildlife Conservation Gala” to raise funds and bring supporters together.

Action Plan:

  1. Create an Event in Event Espresso:
    • Navigate to the Event Espresso Dashboard.
    • Create a new event titled “Wildlife Conservation Gala.”
    • Set the event date, time, and venue information (e.g., June 15, 2024, 7:00 PM, at the Local Nature Preserve).
  2. Define Ticket Types:
    • Create various ticket options:
      • General Admission: $50
      • VIP Admission: $100 (includes a special dinner and a meet-and-greet with conservationists).
    • Add discount codes for members:
      • Wolf Protectors get a 10% discount.
      • Bear Guardians get free admission (automatically applied using MemberPress integration).
  3. Enable Registration:
    • Customize the registration form to collect important information like dietary preferences for VIP attendees.
    • Set a limit on tickets (e.g., only 200 tickets available to keep the event intimate).
  4. Promote the Event:
    • Publish the event registration page on your website and share it through social media.
    • Use Event Espresso’s automated email system to send reminders and updates to registered attendees.

Result:

Your gala is now open for registration. Attendees can easily buy tickets, and your members get special access or discounts based on their membership level.
