Page: {{ site.url }}/recipes/ ## Recipes - [Set up Claude Code with a Brain Vault](https://sethshoultes.com/recipes/claude-code-brain-vault.html): An Obsidian vault wired to Claude Code as persistent memory, with hooks, a save-a-note skill and an auto-committing git repo. (~35 min) - [Wire RAG into an ElevenLabs Agent](https://sethshoultes.com/recipes/add-rag-to-elevenlabs-agent.html): Connect documents to an ElevenLabs voice agent so it retrieves context before it answers, and avoid the page_build trap. (~20 min) - [Register an ElevenLabs Client Tool](https://sethshoultes.com/recipes/register-elevenlabs-client-tool.html): Let a voice agent run functions in the visitor's browser: open modals, scroll to sections, play videos. (~25 min) - [Set Up Canonical Secrets](https://sethshoultes.com/recipes/set-up-canonical-secrets.html): Move every scattered API key into one protected store, audit your .env files and revoke what leaked. (~30 min)
